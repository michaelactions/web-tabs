# 标签浏览器 (WebTabs)

给安卓平板用的「多标签网页 + 屏幕常亮」小工具。

## 功能
- **屏幕常亮**：打开后不会息屏（窗口级 KEEP_SCREEN_ON，也可以在设置里关）
- **多标签**：顶部标签栏，点「＋」添加；每个标签就是一个网页
- **自动保存**：标签列表、当前标签、所有设置都存在本地，重启 App / 重启平板都还在
- **长按标签**：编辑 / 删除 / 刷新 / 查看网址
- **长按「＋」**：打开设置（隐藏标签栏 / 桌面版网页 / 全屏沉浸 / 自动刷新秒数）
- 返回键优先网页后退，不能后退时把 App 收到后台（避免看板被误退出）
- 支持 http（内网看板）与 https；支持下载跳系统浏览器；支持视频自动播放

## 下载
到 [Releases](../../releases) 下载 `WebTabs-v*.apk`，传到平板安装（需允许「安装未知来源应用」）。

## 自己编译
GitHub Actions 自动编译：推送 `main` 或打 `v*` 标签即可，产物在 Actions artifacts / Releases。

本地编译：JDK 17 + Android SDK（platform 34、build-tools 34.0.0）+ Gradle 8.7，然后
```
gradle assembleRelease
```

## 签名
`keystore.p12`（别名 `webtabs`，口令 `webtabs123`）随仓库提交，保证每次构建签名一致、可以直接覆盖安装升级。仅用于个人侧载，不要用于上架。
