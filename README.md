# 标签浏览器 (WebTabs)

给安卓平板用的「多标签网页 + 屏幕常亮」小工具。

## 怎么用
1. 打开 App → **首页就是你自己配置的标签列表**（每个标签自动带该网站的图标）
2. **点哪个就直接进哪个链接**
3. 右上角「＋ 添加」/ 长按标签 → 编辑、删除、上移、下移、刷新图标
4. 右上角「设置」→ 屏幕常亮、显示/隐藏标签栏、全屏沉浸、桌面版网页、自动刷新秒数

## 内置默认标签（装好就自带，不用配）
- 工具站 `https://tools.office3.pp.ua/`
- 节点切换 `https://tools.office3.pp.ua/failover/`
- 状态监控 `https://status.digac.icu/`
- 华住会看板 `https://huazhu.office3.pp.ua/`

这些站**每次打开都会自动补齐**（升级、重装、清数据后都还在）。手动删掉的站不会自己冒出来；想找回来：设置 → 「恢复默认标签」。

**图标已随 App 打包**（`app/src/main/assets/icons/`）：默认站点首屏立刻有图标，**不联网抓取**。
只有当网站那边的图标真的换了，App 才会联网取回新图标并替换（12 小时最多检查一次）。
用户自己加的站，第一次会联网抓一次图标，之后同样只做"变了才更新"。

## 功能
- **屏幕常亮**：打开后不息屏（可在设置里关）
- **标签自己在设置里配**：名称 + 网址，加了什么就有什么，全部存本地（重启 App / 重启平板都还在）
- **进 App 先选**：首页列表展示全部标签，点一个直达该网页
- **自动抓网页图标**：从网站抓 favicon 缓存成本地图标（抓不到就用首字母头像兜底），也能长按「刷新图标」重抓
- 浏览页顶部标签栏可随时切换，长按标签可重载 / 复制网址 / 外部浏览器打开 / 只看这个
- 返回键优先网页后退；首页键 `⌂` 回到标签列表，长按 `⌂` 进设置
- 支持内网 http 看板、下载跳系统浏览器、视频自动播放

## 下载
到 [Releases](../../releases) 下载 `WebTabs-v*.apk`，传到平板安装（需允许「安装未知来源应用」）。

## 自己编译
GitHub Actions 自动编译：推送 `main` 或打 `v*` 标签，产物在 Actions artifacts / Releases。

本地编译：JDK 17 + Android SDK（platform 34、build-tools 34.0.0）+ Gradle 8.7：
```
gradle assembleRelease
```

## 签名
`keystore.p12`（别名 `webtabs`，口令 `webtabs123`）随仓库提交，保证每次构建签名一致、可直接覆盖安装升级。仅用于个人侧载，不要用于上架。
